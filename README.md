# Coldy 鼠标挂件

这是一个只给 Coldy 用的桌面鼠标挂件。Coldy 挂在光标下面的一根绳子上，绳子会跟着鼠标弯曲、摆动。挂件窗口置顶、透明，并且点击穿透，不会挡住你正在使用的程序。

形象使用仓库里的 `assets/coldy.png`。绳子从脑袋顶上的绒毛引出来，头顶的勺子留在绳子旁边。

## 开发方式

程序用 C# 5 和 WinForms 写成，目标框架是 Windows 自带的 .NET Framework 4，没有额外依赖。全部界面、物理和绘制都在 `src/Program.cs` 里，`src/app.manifest` 只负责声明 DPI 感知和 Windows 兼容性。

挂件本身是一个分层窗口。每帧把绳子和人物画进一张带透明通道的位图，再用 `UpdateLayeredWindow` 贴到屏幕上。窗口带有点击穿透，鼠标操作会落到它后面的程序。

绳子是这个仓库里自己写的 Verlet 求解器。绳子被分成固定段数，每一段的长度被约束住，所以它会弯曲而不是被拉长。人物的转角取最后一段的方向。求解按固定时间步推进，鼠标移动过快时会限制单帧步数，静止一会儿后会停住，避免挂件在原地微抖。

光标是程序自己画的。选中一种样式后，会替换系统里常用的几套指针；选择「系统默认」或正常退出时，再把系统光标恢复回来。隐藏快捷键要同时按下两个键，系统的全局热键注册做不到这种组合，所以程序改为轮询这两个键的按下状态，两个键都按下的那一瞬间切换显示。

编译使用框架自带的 `csc`，不需要 Visual Studio：

```bat
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /win32manifest:src\app.manifest /out:Coldy.exe src\Program.cs
```

`Coldy.exe` 要和 `assets` 文件夹放在同一层。程序从 exe 所在目录读取 `assets\coldy.png`。在仓库根目录编译、再从仓库根目录启动，就可以直接找到图片。

## 运行参数

控制台里能改的参数会立刻生效，并写进 exe 旁边的 `coldy.ini`。范围是界面滑条的范围。

| 参数 | 配置项 | 范围 | 初次启动 | 作用 |
| --- | --- | --- | --- | --- |
| 名字 | `name` | 任意文本 | `Coldy` | 窗口标题和托盘提示。留空时按 Coldy 处理 |
| 绳子长度 | `rope` | 40–320 | 120 | 绳子静止长度，单位是像素 |
| 人物大小 | `size` | 80–420 | 190 | 人物显示高度，单位是像素 |
| 光标 | `cursor` | 见下表 | `arrow` | 替换后的系统指针样式 |
| 光标大小 | `cursorSize` | 16–128 | 32 | 指针边长，单位是像素 |
| 隐藏快捷键 | `hotkey`、`hotkeyVk`、`hotkeyVk2` | 两个不同的键 | `F8` | 同时按下时隐藏或显示人物 |

光标取值：

| 界面 | 配置值 |
| --- | --- |
| 箭头 | `arrow` |
| 手型 | `hand` |
| 十字 | `cross` |
| 工字 | `ibeam` |
| 圆点 | `dot` |
| 系统默认 | `system` |

选「系统默认」时，光标大小滑条不起作用，系统指针会恢复成原来的样子。

下面这些参数写在程序里，控制台不能改：

| 参数 | 值 | 作用 |
| --- | --- | --- |
| 绳段数 | 7 | 绳子上的活动段数，点比段多一个 |
| 重力 | 11000 | 每步加到绳子上的下拉力 |
| 模拟步长 | 1/240 秒 | 物理更新的固定间隔 |
| 单帧最长时间 | 0.033 秒 | 卡住之后不会一次补太多步 |
| 单帧最多步数 | 8 | 同上 |
| 画面刷新 | 约 16 毫秒 | 挂件重画间隔 |
| 绳子曲线张力 | 0.45 | 把绳点连成平滑曲线 |
| 快捷键轮询 | 30 毫秒 | 检查两个隐藏键是否都按下 |
| 悬挂偏移 | 光标大小的 0.45 倍 | 绳子上端离开指针热点的距离 |

`coldy.ini` 是运行时生成的，已经在 `.gitignore` 里。换电脑或重装时，把这份文件和 exe 放在一起，上次的名字、绳子、大小、光标和快捷键会保留。

## 使用手册

### 启动

在仓库根目录运行 `Coldy.exe`。会同时出现两样东西：屏幕上的 Coldy，以及标题为当前名字的控制台。通知区域里也会有一个 Coldy 图标。

挂件跟的是系统光标。把鼠标移开，绳子会甩一下再垂稳。

### 控制台

- **名字**：改完后窗口标题和托盘提示一起变。
- **绳子长度**：向右拖更长。松手后的数值会显示在滑条右边。
- **人物大小**：改变的是人物高度，绳子挂点会跟着缩放。
- **光标**：从箭头、手型、十字、工字、圆点里选一个，系统指针马上换成这一种。选「系统默认」则恢复系统原来的指针。
- **光标大小**：只对上面五种自绘指针有效。
- **隐藏快捷键**：见下一节。
- **隐藏人物 / 显示人物**：立刻切换挂件，不需要按快捷键。
- **退出**：关掉挂件和控制台，并恢复系统光标。

### 隐藏快捷键

初次启动的隐藏键是 `F8`。要改成两个键时：

1. 点「隐藏快捷键」。按钮变成「请按两个键」。
2. 两个键可以一起按，也可以先后按。按钮会先显示第一个键，再显示完整组合，例如 `A + S`。
3. 记录过程中按 `Esc` 会取消，沿用原来的组合。
4. 记好之后，只有这两个键都按住时才会隐藏或显示人物。按一下就会切换，按住不放不会连续切换。

快捷键在控制台没有焦点时也有效，隐藏之后同样有效。托盘菜单里的「隐藏人物」和窗口上的按钮做的是同一件事。

### 托盘

右键通知区域的 Coldy 图标：

- **显示控制台**：把控制台带到前面。双击图标也是这个作用。
- **隐藏人物**或**显示人物**：切换挂件。
- **退出**：结束程序并恢复系统光标。

### 退出

用控制台上的「退出」、托盘里的「退出」，或者直接关掉控制台窗口。这三种方式都会把系统光标恢复回去。

不要在任务管理器里直接结束 `Coldy.exe`。那样做会跳过恢复，自定义指针会留在系统里，直到你重新打开本程序再正常退出。

## 目录

```
src/Program.cs       挂件、绳子、控制台、光标
src/app.manifest     DPI 感知和系统兼容声明
assets/coldy.png     程序实际使用的透明形象
Coldy.exe            编译结果，不进入版本库
coldy.ini            本机配置，不进入版本库
```
